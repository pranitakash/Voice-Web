# 🎙️ Voice Web — AI Voice Site Studio

> **Stop clicking. Start speaking. Build the future.** 🚀✨

**Voice Web** is a cutting-edge, **voice-first website builder** that bridges human language with high-end digital design. It enables creators to build **production-ready website layouts simply by speaking**, powered by **Generative AI** and rendered on a **high-performance Infinite Canvas**.

---

## 🌐 What is Voice Web?

Voice Web transforms spoken language into structured, cinematic website sections in real time.  
Instead of dragging components or writing boilerplate code, users **orchestrate layouts using natural voice commands**, making website creation faster, more intuitive, and more creative.

---

## 🛠️ Tech Stack

Built with a **Modern–Premium** philosophy to ensure speed, scalability, and a polished tactile experience.

- **Framework:** Next.js 14 (App Router, Server Actions)
- **Styling:** Tailwind CSS (High-contrast Dark Mode architecture)
- **Animations:** Framer Motion  
  *Pop-in entries, cinematic hover zooms, glassmorphism transitions*
- **Voice Engine:** Web Speech API (`webkitSpeechRecognition`)  
  *Optimized for low-latency intent parsing*
- **AI Backend:** Google Gemini API  
  *Generates dynamic UI sections from natural language*
- **State Management:** Zustand  
  *Synchronizes voice commands with the global canvas state*
- **Database & Authentication:** Firebase Firestore & Firebase Auth  
  *Persistent user profiles, avatars, and generation history*

## 🎨 Design Philosophy — *“Cinematic Tactical”*

Voice Web isn’t just a builder — it’s a **visual experience**.

### ✨ Core Design Principles

- **Infinite Canvas**  
  A dot-grid workspace where sections materialize in real time as you speak.

- **High-Contrast Aesthetics**  
  Deep `#050505` backgrounds with vibrant **Indigo & Purple** accents.

- **Glassmorphism UI**  
  Navbars, command bars, and modals use:
  - Heavy backdrop blurs  
  - Subtle white borders  
  - Apple-like premium translucency

- **Interactive Cards (Multi-Layered Animations)**  
  Each card features:
  - **The Lift:** Vertical Y-axis elevation  
  - **The Zoom:** Header image scales & rotates slightly  
  - **The Glow:** Indigo radial gradient on hover
